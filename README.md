# キャラ画像メーカー

ミル子ちゃん・ミルンくん・てんてん・ノイズ星人のポーズと表情を選んで、背景が透明の PNG で保存するページです。佐野ケーブルテレビの社内用です。

## 中身

- `index.html`：ページ本体
- `mirumiru/`：ミル子ちゃん・ミルンくんを描くコード（「ミル子ミルン_動く絵」から写し、目を片方ずつ閉じられるようにしたもの）
- `tenten/`：てんてんの3D（「tenten-3d-work」から写したもの。表情ごとの絵は 2048px）
- `noise/`：ノイズ星人のドット絵（STAR SHOT! の `ss-chars.js`）

three.js 0.170.0 は jsDelivr から読みます。

## 手元で開く

画像を読むので、ファイルを直接開かずにローカルのサーバーで開きます。

```bash
python3 -m http.server 8000
```
